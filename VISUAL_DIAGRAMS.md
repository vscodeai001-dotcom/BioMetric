## Database Query Sequence

### Dependency Check Flow

```
START: User clicks "Delete"
  ?
  ??? [Query 1]  SELECT COUNT(*) FROM attendance_logs 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 2]  SELECT COUNT(*) FROM payroll_histories 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 3]  SELECT COUNT(*) FROM salary_advances 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 4]  SELECT COUNT(*) FROM leave_requests 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 5]  SELECT COUNT(*) FROM shift_schedules 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 6]  SELECT COUNT(*) FROM bonus_records 
  ?              WHERE employee_id = ?
  ?
  ??? [Query 7]  SELECT COUNT(*) FROM daily_summaries 
                 WHERE employee_id = ?
  ?
  ? [ALL QUERIES EXECUTE IN PARALLEL]
  ?
  ?
SUM(all counts)
  ?
  ??? [0 records]   ? CanDelete = true
  ?
  ??? [>0 records]  ? CanDelete = false
       ?
       ?
  Build BlockReason message
  Return EmployeeDeletionDependencies
```

### C# Method Call Sequence

```
EmployeeList.razor

    ?
    ?? EmployeeDeletionService.cs
        ?
        ?? CheckDeletionDependenciesAsync(employeeID)
            ?
            ??? Get employee (FindAsync)
            ?
            ??? Parallel.WhenAll([
            ?       AttendanceLogs.CountAsync(),
            ?       PayrollHistories.CountAsync(),
            ?       SalaryAdvances.CountAsync(),
            ?       LeaveRequests.CountAsync(),
            ?       ShiftSchedules.CountAsync(),

### Example 2: Long-tenured Employee

```
Employee: Sarah Johnson (ID: 42)
- Hired: 3 years ago
- Status: Active
- Attendance Logs: 1,000+ entries
- Payroll History: 36 months
- Advances: 12 records
- Leave: 15 records
- Bonuses: 8 records

## Error Handling Examples

### Network Timeout

```
User clicks Delete
Dialog opens... Loading...
[DB connection timeout]

Result:
Dialog shows:
  ? "Cannot delete this employee"
  Message: "Error checking dependencies: 
            Connection timeout"
  [Close] [OK]

System logs:
  ERROR: "Error checking deletion dependencies 
         for employee 42"
  
User sees:
  Toast notification: "Error checking records: 
                      Connection timeout"
```

### Database Constraint Violation

```
System tries to soft-delete:
Set IsDeleted = true
Save to DB

[Constraint violation - shouldn't happen but...]

Result:
Catch block executes:
  CanDelete = false
  BlockReason = "Error deleting: 
                Foreign key constraint failed"
  
User sees:
  Toast: "Error: Foreign key constraint failed"
  System logs issue
```

## UI State Transitions

```
Initial State:
- showDeletionDialog = false
- deletionDependencies = null
- isDeletionCheckLoading = false
- isProcessingDeletion = false

? [Click Delete]

Checking State:
- showDeletionDialog = true
- isDeletionCheckLoading = true
- [Modal shows spinner: "Checking employee records..."]

? [Dependency check complete]

Result State (CAN DELETE):
- isDeletionCheckLoading = false
- deletionDependencies.CanDelete = true
- [Modal shows green alert: "Can Delete"]
- [Delete button ENABLED]

Result State (CANNOT DELETE):
- isDeletionCheckLoading = false
- deletionDependencies.CanDelete = false
- [Modal shows red alert: "Cannot Delete"]
- [Modal shows dependency list]
- [Delete button DISABLED]

? [Click "Move to Recycle Bin" (if enabled)]

Processing State:
- isProcessingDeletion = true
- [Modal shows: "Moving to Bin..."]

? [Deletion complete]

Success State:
- showDeletionDialog = false
- [Toast: "Moved to Recycle Bin"]
- [Employee list refreshes]
- [Employee no longer visible]
```
